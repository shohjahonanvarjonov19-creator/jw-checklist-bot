# JW Marriott Tashkent — Checklist Bot

Telegram-бот для чек-листов белбоев и консьержей. Сотрудник открывает
бота, выбирает свою роль, проходит пункты по одному, и по завершении
бот отправляет отчёт в группу менеджеров.

## Как это работает

1. `/start` → сотрудник выбирает "Белбой" или "Консьерж"
2. Бот показывает пункты чек-листа по одному с кнопкой **✅ Готово**
3. После последнего пункта бот:
   - подтверждает сотруднику, что чек-лист завершён
   - отправляет отчёт (имя, роль, время) в группу менеджеров

## Установка

```bash
npm install
cp .env.example .env
```

Заполните `.env`:
- `BOT_TOKEN` — получите у [@BotFather](https://t.me/BotFather) (`/newbot`)
- `MANAGERS_CHAT_ID` — chat_id группы менеджеров в Telegram

### Как узнать MANAGERS_CHAT_ID

1. Создайте группу в Telegram для менеджеров
2. Добавьте туда бота
3. Напишите в группе `/chatid` — бот ответит числом (обычно отрицательным, например `-1001234567890`)
4. Впишите это число в `.env`

## Запуск

```bash
npm start
```

## Редактирование пунктов чек-листа

Все пункты — в файле **`checklists.js`**. Просто отредактируйте
массивы `items` для `bellboy` и `concierge`, ничего в `bot.js`
трогать не нужно. Пункты в файле сейчас — плейсхолдеры, замените
их на реальный список.

## Деплой

Как и с e-concierge ботом, подойдёт бесплатный тариф Render.com
(Background Worker, не Web Service, так как это polling-бот) +
UptimeRobot, если понадобится держать процесс активным.

## Возможные доработки

- Отдельные чек-листы для утренней/вечерней смены
- Учёт причины пропуска пункта (не просто "Готово", а "Готово" / "Пропущено, потому что...")
- Простая статистика — сколько чек-листов пройдено за смену/день
